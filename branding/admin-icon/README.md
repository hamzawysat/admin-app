# Admin app icon

Upload the approved admin launcher image here as `admin_icon.jpg`.

Android launcher resources cannot reference files in this documentation folder directly. The same image must also be copied to:

`app/src/main/res/drawable-nodpi/admin_icon.jpg`

The launcher resources in `app/src/main/res/mipmap-anydpi/` and
`app/src/main/res/mipmap-anydpi-v26/` already reference that Android drawable.
This folder is reserved for the original admin icon asset only.

Do not place or replace the customer/technician app icon here.
