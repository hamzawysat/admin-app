# Notification sound asset

This folder is the dedicated location for the Admin App's custom, unified notification sound.

## Upload the sound here

Add the approved audio file in this folder. Preferred filename: `notification_logo.wav`.

Accepted source formats: `.wav` or `.ogg`. Keep the original audio file; do not replace it with a converted or compressed version unless requested.

The app integration should reference this single shared asset so notification sound behavior stays consistent. Uploading the asset here does not by itself change the app's runtime notification settings.
